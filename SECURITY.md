# Security policy

If you find a security issue in See Attached, please do not open a public GitHub issue.

Email see-attached-reports@inbox.manageease.com. You can also use GitHub's private vulnerability reporting on this repository (Security → Report a vulnerability).

This project compiles JSON into HTML and prints it with Chromium. Please include the report definition, the data file, and the steps that show the problem, with any confidential values removed.
